# 울산 야화 V12 · 서버형 관리자

## 실행 방법
Python 3.9 이상 설치 후 이 폴더에서 실행합니다.

**Windows PowerShell**
```powershell
$env:YAHWA_ADMIN_PASSWORD='여기에_12자_이상_강력한_비밀번호'
python server.py
```

**macOS / Linux**
```bash
export YAHWA_ADMIN_PASSWORD='여기에_12자_이상_강력한_비밀번호'
python3 server.py
```

- 방문자 홈페이지: http://localhost:8000/
- 관리자 사이트: http://localhost:8000/admin.html

## 주요 기능
- 23개 업소 출근 인원, 예약 현황, 주대, T.C., 영업시간, 주차 정보 수정
- 공지 등록·삭제
- 방문자 후기 접수 → 관리자 승인 시 공개
- SQLite 영구 저장 (`yahwa.sqlite3`), 관리자 비밀번호 로그인, CSRF 토큰, 변경 이력(업소 수정)
- 미등록 정보는 임의로 생성하지 않음

## 운영 전 주의
- ZIP에는 데이터베이스 파일이 포함되지 않습니다. 서버 첫 실행 시 자동 생성됩니다.
- **인터넷 공개 전 HTTPS와 리버스 프록시, 로그인 시도 횟수 제한, 정기 백업을 설정하세요.**
- 현재 서버는 단일 관리자 비밀번호 기반의 소규모 시제품입니다. 다중 계정/권한 분리, 이미지 업로드, 보안 감사 및 실시간 예약 시스템은 미구현입니다.
- 외부 영상 주소가 만료되면 홈페이지 배경은 기존 이미지로 대체됩니다.
- 정적 HTML을 파일로 직접 열면 서버 API가 없어 관리자 저장 기능은 작동하지 않습니다.
